# Where Oh Where Has My Fish Gone!
Classifying Fish from Echosounder Data

A classifier that labels fish species (hake, herring, salmon, juvenile salmon) in echosounder data collected by DFO in the Malaspina Strait.

---

## Repo layout
- `notes/`: background and research notes
- `data/`: where the data goes (not committed)
- `scripts/count_species_evr.py`: counts labelled regions per species, week and folder from the `.evr` files in `data/` (`python scripts/count_species_evr.py`); CSVs go to `data/`

---

## Getting the data
The data is confidential and too big, so it isn't in the repo.

1. Clone the repo
2. Ask me for the sample files
3. Put them in `data/`, keeping the folder structure
